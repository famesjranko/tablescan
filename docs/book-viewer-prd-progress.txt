## BV-005: Add TableSelection CRUD API endpoints [COMPLETE]
- Added TableSelectionViewSet to api/views.py
- Endpoints:
  - GET /api/reports/{id}/selections/ - list selections for report
  - GET ?page_num= - filter by page number
  - GET ?status= - filter by status (comma-separated, e.g., ?status=pending,approved)

- All endpoints require authentication
- Report ownership enforced (returns 404 if not owned)
